🛒

חנות

מנהלים יכולים להוסיף מוצרים עם מחיר ותיאור, ומשתמשים יכולים לקנות אותם.

🎒

Inventory

כל הפריטים שקנית נשמרים במלאי האישי שלך.

🏆

Leaderboard

דירוג של המשתמשים עם היתרות הגבוהות ביותר בשרת.

⚙️

ניהול

מנהלים יכולים לנהל כסף ומוצרים באמצעות פקודות מיוחדות.

פקודות

הפקודות הזמינות כרגע בבוט

/balance מציג את כמות הכסף שלך
/shop פותח את החנות
/inventory מציג את הפריטים שלך
/leaderboard מציג את דירוג הכסף
/addmoney מוסיף כסף למשתמש — Admin
/removemoney מוריד כסף ממשתמש — Admin
/setmoney קובע יתרה למשתמש — Admin
/additem מוסיף מוצר לחנות — Admin
/removeitem מסיר מוצר מהחנות — Admin
/shopitems מציג את מוצרי החנות — Admin
